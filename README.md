# Daily Learning Log

A running log of short daily notes on things I'm learning across software
engineering, systems, and adjacent topics. One note per day, kept short
(150–300 words) — the goal is consistent reflection, not exhaustive coverage.

Notes live in [`notes/`](./notes), one file per day, named
`YYYY-MM-DD-<topic-slug>.md`.

## Topics

I rotate through a curated pool covering algorithms, data structures, system
design, networking, databases, distributed systems, security, language
features, developer tooling, and adjacent territory. Each note aims to answer
"what is this / when is it useful / one concrete example or gotcha".

## Why

Small daily habit. Writing down what I read forces me to actually understand it.
